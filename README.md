I follow questions until they become systems that can be built, inspected, and
tested. My work moves between protocols, low-level runtimes, complex systems,
hardware experiments, and small tools that solve a problem I actually had.

## Active system

**[ChatCommons](https://github.com/TT1nKer/chatcommons)** is an offline-first
protocol for community-owned chat. It is currently a friends-and-contributors
alpha: signed events, replaceable home servers, direct or relayed QUIC, and a
small native text client exist; a production service, trusted release binary,
voice, recovery, and multi-device identity do not.
